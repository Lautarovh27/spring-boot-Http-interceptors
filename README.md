# Spring Boot HTTP Interceptors

Proyecto desarrollado para practicar el uso de **Interceptors** en Spring Boot, permitiendo interceptar solicitudes HTTP antes y después de que lleguen a los controladores.

## 🚀 Tecnologías utilizadas

* Java 21
* Spring Boot
* Maven
* Spring MVC
* REST API

## 📚 Conceptos aplicados

* Interceptores HTTP (`HandlerInterceptor`)
* Métodos `preHandle`, `postHandle` y `afterCompletion`
* Configuración de interceptores con `WebMvcConfigurer`
* Intercepción de peticiones REST
* Registro y monitoreo de solicitudes
* Arquitectura MVC

## 📂 Estructura del proyecto

```text
src
├── controllers
├── interceptors
├── config
├── models
└── SpringBootHttpInterceptorsApplication
```

## 🎯 Objetivo

Comprender cómo funcionan los interceptores en Spring Boot para ejecutar lógica transversal antes y después del procesamiento de una petición HTTP.

## ⚙️ Funcionalidades

* Intercepción de solicitudes entrantes.
* Ejecución de lógica previa al controlador.
* Procesamiento posterior a la ejecución del controlador.
* Registro de información de las peticiones.
* Configuración centralizada de interceptores.


## 📖 Aprendizajes

Durante este proyecto se trabajó con:

* Ciclo de vida de una petición HTTP.
* Interceptores en Spring MVC.
* Configuración mediante `WebMvcConfigurer`.
* Separación de responsabilidades.
* Desarrollo de APIs REST.
* Buenas prácticas en aplicaciones Spring Boot.
